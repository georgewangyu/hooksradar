# Hooks Radar Design Contract

Hooks Radar should feel like a public hook lab for first-frame, on-screen text,
spoken openings, and payoff structures. It is not a generic social-media tips
blog.

## First Screen

The first viewport should show:

- what Hooks Radar helps create
- one or more strong hook examples
- search/filter access to reusable patterns
- install/request paths without hiding the catalog

## Layout

- Pattern cards should make formula, use cases, source strength, and payoff
  scannable.
- Detail views should separate public examples from private source context.
- Reference-video receipts should be compact and source-aware.

## Typography And Color

- Use George Research Desk tokens as the baseline.
- Clay is the primary accent for creative tension.
- Keep backgrounds warm and readable; do not use creator-platform color washes.

## Do

- Make the hook shape inspectable in the first few seconds.
- Keep source strength visible.
- Preserve the public/private export boundary.

## Do Not

- Copy creator identity or private story details.
- Publish raw transcripts or long comment dumps.
- Use generic creator-economy gradients.
- Let cards nest inside other cards.
